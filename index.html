This project explores both art and technology, creating an enjoyable user experience. Capturing fireflies will generate a poem from the PoetryDB.

Multi-Page Website

This is a multi-page website and interactive experience. The webpages guide the user through the experience of screen addiction. It includes html design, css design, and Instagram posts designed in canva with photography.

Course Goals


1. Consider technology’s role in acts of making

In some ways, code allows us more flexibility to be creative and allows media to become more complex. It allows for creative works that are both combined media and infinite. Technology also allows for works to be both accessible and interactive. In the New Media Art, technology assistance in providing a seemingly infinite experience. Editing in Canva is used to satirize Instagram in the Multi Page Website.

2. Embrace experimentation

Experimentation is essential because, without it, I would never know what is possible. This is especially true when using new tools and techniques. In New Media Art, I experiemented with moving rings, buttons, and functions. In the Multi Page Website, I experimented with mixing media and page navigation.

3.Engage with others in a workshop environment

In the workshop environment, I was able to discuss perspectives on the readings, inspiring new ideas, approaches, and topics for future works such as the impacts of social media. It took work to understand concepts such as Derrida's work before discussing. After reviewing past work with peers, I was inspired to expand upon the Dear Data graphs incorporated into the Code and Technology Narrative.

4. Practice revision within and across media forms

Working across media forms allows for revision in many ways. I had to revise my ideas, media choices, and implementation in multiple iterations. In New Media Art, I had to reference many YouTube videos and W3 School pages in order to implement my design. In the Multi Page Website, I had to rescale my idea so that I could apply it to five total pages. The flow from one page to another had to be revised, and I had to decide if I wanted to turn images edited from Canva into buttons or use css styled buttons.

5. Learn to present your work

Learning to present my work was a challenge, as I had to both share my work and communicate the principles behind it. To do this, I had to put Derrida's concepts into words. Sharing my work also allowed for improvement. Oher students struggled in similar ways with the sizing of images or how they were displayed.
